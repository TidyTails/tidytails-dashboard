1

Open your site's homepage HTML

In Cloudflare Pages, go to your repo → find index.html (or however your homepage is structured)

2

Find </head>

Search (Ctrl+F) for </head> — it's near the top of the file

3

Paste the schema block BEFORE it

The schema code goes right before that closing head tag. Save the file.

4

Push to GitHub → Cloudflare auto-deploys

Commit and push. Cloudflare will rebuild in ~1 minute.

5

Validate at Google's Rich Results Test
