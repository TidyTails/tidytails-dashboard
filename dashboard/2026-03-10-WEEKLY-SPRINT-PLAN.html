Wednesday, Mar 11
Google Foundation Day — The #1 Blocker
~40 min ▼
Set up Google Search Console
Go to search.google.com/search-console → Add property → Enter tidytailsstl.com → Verify via DNS TXT record (Squarespace: Settings → Domains → DNS Settings). Submit sitemap URL: tidytailsstl.com/sitemap.xml. Request indexing for homepage + 4 city pages.
15 min 🚨 Critical SEO Rescue Plan →
Create Google Business Profile
Go to business.google.com → Create profile → Business name: "Tidy Tails Pet Waste Removal" → Category: "Pet Waste Removal Service" → Service area: St. Louis County + St. Charles County → Add phone, website, hours. Verification will take ~1 week via postcard/phone.
15 min 🚨 Critical GBP Playbook →
Set up Bing Webmaster Tools
Go to bing.com/webmasters → Sign in with Microsoft account → Import from GSC (one-click) or add manually. Covers Bing + DuckDuckGo + Brave Search indexing.
5 min Easy

Website Quick Wins — 3 Fixes, 15 Minutes
~30 min ▼
Fix hero pricing: "$25/week" → "Plans from $70/month"
Right now the hero makes TJ look expensive ($25/week = $108/mo). Competitors show monthly ($78-95/mo). Switching to "Plans from $70/month" instantly makes TJ the cheapest option AND matches how competitors price. Edit in Squarespace.
5 min High Impact Conversion Audit →
Add "First Visit FREE" to homepage
Doggie Doodies offers a free initial cleanup. TJ should too. Add a banner or button: "Try us free — first cleanup on us, no commitment." Reduces purchase anxiety massively.
10 min High Impact
Add phone number to homepage header
City pages have it, homepage doesn't. Some people want to call, not fill out forms. Make the phone number clickable (tel: link) in the site header on every page.
