    Click "Create Campaign" in Ads Manager

Campaign Setup
  • 4

    Campaign Name

    "Tidy Tails — Spring 2026 — Messages"

  • 5

    Budget: Campaign Level

    Start at $7/day (Advantage Campaign Budget — let FB split it). Don't set it higher until Day 5.

  • 6

    Ad Set: Apply Targeting from Targeting Tab

    Location → 15 miles from 63031. Age 25-55. Add interests from the list. Turn off Audience Network.

  • 7

    Create Ad #1 (Quick Math)

    Upload your Canva image. Paste text from the Ad Copy tab. Set CTA to "Send Message." Set destination to Messenger.

  • 8

    Duplicate Ad → Create Ad #2 (Spring Urgency)

    In the same ad set, duplicate Ad #1 and swap the copy + image. Now you're A/B testing automatically.

  • 9

    Review + Publish

    FB takes 1-24 hours to approve. Usually 1-2 hours if everything looks clean (no "FREE" in headline, no sensational claims).

After Publishing

  • Set a "Day 3 reminder" to check results

    Don't touch it before Day 3. FB needs time to exit the learning phase.

    Mon

  • Watch for the first message to come in

    Set up a Facebook Page auto-reply: "Hey! Thanks for reaching out to Tidy Tails. I'll get back to you within 2 hours. What area are you in?" — reduces response time, boosts ad score.

    Mon

  • Day 3 (Thu): Check Cost Per Message

    Under $10/message = keep running. $10-20 = adjust targeting. Over $20 = pause and swap creative.

    Thu

  • Day 5 (Sat): Kill the loser, scale the winner

    Pause the ad with higher CPM. Increase budget on winner to $10/day.

    Sat

  • Week 2: Add Ad #5 (North County)

    Create the separate North County ad set with zip code targeting. This is your expansion lever.

    Apr 6
⚠️ Common FB Ad Mistakes to Avoid:
— Don't "boost post" — always use Ads Manager
— Don't change the budget or creative in the first 3 days
— Don't run more than 2 ads per ad set until you know your winner
— Don't use "FREE" in the headline (FB penalizes it) — use "First Visit On Us" instead
— Don't turn it off at night — let FB optimize 24/7
