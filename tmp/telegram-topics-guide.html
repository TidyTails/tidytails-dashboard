📱 Telegram Topics Setup Guide

Separate your businesses into organized channels — 5 minutes to set up

What This Does

Telegram "Topics" turns one messy chat into organized channels — like Slack but in Telegram. You'll get a dedicated space for Tidy Tails, Sheds, Daily Accountability, and more. Franklin responds contextually in each one.

✅ No more scrolling through shed talk to find dog waste leads. Everything stays in its lane.

Setup Steps

1 Create the Group ~1 minute

  1. Open Telegram → Hamburger menu (☰) → New Group
  2. Name it: "HQ" (or "Command Center" — whatever you want)
  3. Add the Franklin bot as a member (search for the bot username)
  4. Tap Create

2 Enable Topics ~1 minute

  1. Tap the group name at the top → Edit (pencil icon)
  2. Scroll down → Toggle Topics ON
  3. Save

3 Create These 5 Topics ~3 minutes

Tap the "+" button in the group to create each topic:

#Topic NameWhat Goes Here
1🐕 Tidy TailsLeads, customers, marketing, scooping schedule
2🏠 ShedsTuffShed quotes, ads, lot updates, lumber news
3📋 Daily AccountabilityMorning briefings, EOD recaps, task tracking
4🤖 Franklin AdminAgent status, system stuff, skill updates
5🚗 MOTRAAutonomous vehicle venture (parked for now)

4 Tell Franklin ~30 seconds

  1. Send a message in each topic (anything — even "test")
  2. Come back to this DM and tell Franklin: "HQ group is ready"
  3. Franklin will grab the IDs automatically and configure everything
💡 Pro Tip: Pin a brief "what goes here" message in each topic so you remember the purpose when scrolling fast.

FAQ

Can I still DM Franklin directly?

Yes — this DM stays as-is. The group is in addition to your current chat, not a replacement.

What if I message in the wrong topic?

No big deal. Franklin will still respond. Just move the convo to the right topic when you can.

Does this cost anything?

Nope. Telegram Topics is a free feature. No extra API costs either.
