2. **Zero backlinks:** No other website links to tidytailsstl.com. Zero domain authority.
3. **Zero reviews:** Google, Yelp, BBB — all zero. Review signals are a top ranking factor.
4. **Brand collision:** 8+ "Tidy Tails" businesses nationally dilute branded search.
5. **No directory presence:** Not listed on BBB, SuperPages, Yellow Pages, PetWorks, BringFido, PoopButler, etc.
6. **GBP only 7% complete:** Google's local pack relies on GBP completeness + reviews.
