## Rotation Rules

1. **Every hour, pick from a DIFFERENT area** than the last task
2. **Prioritize by impact:** Lead gen > content > systems
3. **After each task:**
   - Update `dashboard/index.html` (Franklin's Work section)
   - Update `docs/FRANKLINS_WORK_LOG.md`
   - Push to GitHub
4. **Track completion** by checking off items above
5. **If stuck:** Research competitors or create more ad variations (always valuable)
