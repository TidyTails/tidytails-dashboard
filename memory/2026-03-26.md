- **Root cause:** Notion paragraphs with URLs in the `content` field but no `link` property = plain text, not hyperlinks. Need `bookmark` block type for clickable links.
- **Fix applied:** Added clickable `bookmark` blocks to ALL 68 content pages (EODs, Briefings, Shed Ads, Commercial Leads, etc.)
- **Prevention:** Updated `auto-notion-sync` SKILL.md with explicit warnings about bookmark vs paragraph blocks, added wrong/right examples
- **Lesson #23:** Notion `paragraph` blocks with URLs in text content are NOT clickable. ALWAYS use `bookmark` block type for PDF links. This was broken since day 1 (Feb 19) and nobody caught it until now.
