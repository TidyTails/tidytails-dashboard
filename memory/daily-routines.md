# Daily Routines

## Hourly (Every Hour on the Hour)
**Autonomous Task** → Execute + Log
- Pick ONE high-impact task toward goals
- Execute it fully
- Log to memory/franklin-tasks.md
- Update Franklin task board on dashboard
- Push to GitHub
- No Telegram notification (silent work)

## Morning (8:00 AM)
**Self-Directed Work** → Execute + Report to TJ
- Review goals and current state
- Generate 4-5 tasks I can do RIGHT NOW on TJ's computer
- Execute those tasks immediately
- Log to daily-logs/
- Update dashboard task board
- Telegram TJ: what I'm working on, what I completed, any access I need

## Morning (8:30 AM)
**Morning Briefing** → Email to TJ + Dashboard
- TuffShed current promotions (scrape tuffshed.com)
- Tidy Tails tasks for the day
- TuffShed sales tasks (pipeline follow-ups)
- **1 NEWS STORY** relevant to TJ (AI, small biz, sales, sheds, pet industry, entrepreneurship)
- **2 BUSINESS IDEAS** TJ could start
- **4 TASKS** Franklin could handle but isn't yet
- Categorized: 🐕 Dog Waste / 🏠 Sheds / ⚙️ Systems / 💡 News & Ideas

## Morning (9:00 AM)
**Shed Ad Copy PDF** → Email to TJ + Upload to Dashboard
- 4 different ad copies
- Based on current TuffShed promos
- Vary style, don't repeat previous copy

**Commercial Leads PDF** → Email to Jamie
- 5-7 leads for the day
- Include: Business name, contact info, why they're a good fit
- Track in leads database to avoid doubles

## Evening (7:00 PM)
**End of Day Summary PDF** → Email to TJ
- What we accomplished today (itemized by section)
- Tidy Tails progress
- TuffShed progress
- Any issues/blockers
- Summary of tomorrow's priorities

## Overnight (Proactive)
- Monitor AI/tool news (OpenClaw, Anthropic, OpenAI)
- Implement security updates without asking
- Research, prep for next day
- Use token budget productively
- **Check Tidy Tails website** for improvements
- **Check dashboard** — add tools, resources, anything useful
- **Check competitor websites** — learn, adapt, improve
- Update dashboard with new tools/resources as found
- Set dashboard status to "working" when active

- **URL:** https://tidytails.github.io/tidytails-dashboard/

- **Documents:** dashboard/docs/ (markdown) + dashboard/pdfs/ (PDF versions)
- **All deliverables must be:**
  1. PDF format
  2. Emailed to TJ/Jamie
  3. Uploaded to dashboard Documents tab
  4. Filed in dashboard/pdfs/

## PDF Deliverables (Daily)
1. Morning Briefing PDF (8:30 AM) → email TJ + dashboard
2. Shed Ad Copy PDF (9:00 AM) → email TJ + dashboard
3. Commercial Leads PDF (9:00 AM) → email Jamie
4. End of Day Summary PDF (7:00 PM) → email TJ + dashboard

## Key Principles
- **No double contacts** - track everything
- **No repeated ad copy** - archive what's been used
- **Organized memory** - TJ shouldn't have to repeat himself
- **Proactive** - don't wait to be asked
- **Dashboard is central** - everything goes there
- **Show work** - status indicator should reflect activity
