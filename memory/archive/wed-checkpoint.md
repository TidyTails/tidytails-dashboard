# Wednesday Mid-Week Checkpoint
**Created:** Feb 25, 2026 6:00 AM
**Purpose:** Get real data on Week 2 execution before building anything else

---

## The 30-Second Check-In (SEND AT 8:30 AM)

```
Hey TJ! Quick Week 2 checkpoint — 30 seconds:

1️⃣ GBP claimed yet? (Y/N)
2️⃣ Posted in any FB groups this week? (Y/N)  
3️⃣ Biggest thing stopping you? (one word)

That's it. Need this to know where to focus. 👍
```

---

## Why These 3 Questions

| Question | What It Tells Us |
|----------|------------------|
| GBP | Did the #1 priority from Monday happen? |
| FB Posts | Is free marketing happening at all? |
| Blocker | What's actually in the way? |

---

## Expected Responses + What to Do

**If GBP = Y:**
- 🎉 Celebrate the win
- Move to "post in 2 FB groups today"

**If GBP = N:**
- Ask: "What's blocking it?" 
- Offer to call/walk through together
- Don't add more tasks

**If FB Posts = Y:**
- Ask: "Which groups? Any responses?"
- Track actual results

**If FB Posts = N:**
- This is fine if GBP didn't happen yet
- One thing at a time

**If Blocker = "time":**
- Reduce task list further
- Focus on 1 thing that takes <5 min

**If Blocker = "confused":**
- The tools are too complex
- Simplify or offer live help

**If Blocker = "forgot":**
- Need reminder system
- Set up daily text reminder

❌ Suggest additional tasks
