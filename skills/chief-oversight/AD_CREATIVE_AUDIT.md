# Ad Creative Audit Standards

**Reference:** `references/ad-creative-standards.md` (full framework)

## Mandatory Audit Checklist

When Chief audits ANY ad creative (static, video, short-form, long-form), apply these standards:

---

## 1. Strategic Alignment (Concept Check)

- [ ] **Single message clarity** — Does the ad communicate ONE clear job-to-be-done?
- [ ] **Audience fit** — Is the message appropriate for the target audience's beliefs and stage?
- [ ] **Platform nativeness** — Is this TikTok-first / Facebook-first / YouTube-first, or generic?
- [ ] **Brand fit** — Does it match Tidy Tails / TuffShed / Consulting voice and positioning?

**Fail conditions:**
- Multiple competing messages = FAIL
- Tone-deaf to audience = FAIL (ref: Pepsi Kendall Jenner disaster)
- Repurposed content that ignores platform norms = FAIL

---

## 2. Hook & Attention (First 3 Seconds)

Research shows **47% of video value is delivered in first 3 seconds**.

- [ ] **Pattern interrupt** — Does the first frame stop the scroll?
- [ ] **Comprehension** — Can you understand the offer with sound off?
- [ ] **Branding** — Is brand visible within first 3-5 seconds?

**Hook types to check for:**
- Shock / Pattern interrupt
- Question / Curiosity
- Problem-first
- Outcome-first
- POV confession
- Demo start
- Social proof

---

## 3. Platform Specifications

### TikTok
- [ ] Duration: 5-60 seconds (recommended 21-30s)
- [ ] Aspect ratio: 9:16 vertical
- [ ] NOT overly polished (users prefer authentic)
- [ ] Audio required (not static/silent)
- [ ] Safe zones respected (UI overlays)
- [ ] Trends used appropriately (if any)
- [ ] Structure: Hook → Body → Close

### YouTube
- [ ] ABCDs applied:
  - **A**ttention in first 5 seconds
  - **B**randing early and repeated
  - **C**onnection via emotion/story
  - **D**irection with single CTA
- [ ] Bumper: ≤6 seconds
- [ ] Non-skippable: 7-15 seconds
- [ ] Skippable: 15-60+ seconds

### Facebook/Instagram
- [ ] Aspect ratios correct (1:1 feed, 9:16 stories/reels, 16:9 in-stream)
- [ ] Text legible on mobile
- [ ] Safe zones for stories/reels
- [ ] CTA clear and visible

### Static/Carousel
- [ ] Single focal point
- [ ] Single claim
- [ ] Legible typography (mobile-first)
- [ ] High contrast

---

## 4. Production Quality

- [ ] **Resolution** — HD minimum (no pixelation)
- [ ] **Audio clarity** — Clear VO/music, no distortion
- [ ] **Text legibility** — Readable on mobile at actual size
- [ ] **Logo presence** — Brand mark visible and correctly placed
- [ ] **Safe zones** — Critical elements not cut off by UI

**TikTok Policy Requirements:**
- Must be dynamic (not mostly static images)
- Audio quality must be clear
- Must meet minimum resolution requirements

---

## 5. Compliance & Legal

- [ ] **Claim substantiation** — Any quantified claims documented?
- [ ] **Required disclaimers** — Present and legible?
- [ ] **Music rights** — Cleared for commercial use?
- [ ] **Influencer disclosure** — FTC compliant if UGC/endorsement?
- [ ] **Contact info** — Phone number correct?
  - Tidy Tails: **314-850-7140**
  - Sheds: **636-354-7406**
  - Consulting: **636-354-7406**
- [ ] **Pricing accuracy** — Current promos reflected?

---

## 6. Variation & Testing Readiness

A single ad is not a strategy. Check for:

- [ ] **Multiple hooks** — At least 3 hook variations?
- [ ] **Multiple proof types** — Demo, testimonial, data/authority?
- [ ] **Multiple CTAs tested** — Shop now vs Learn more?
- [ ] **Cutdowns available** — 6s, 15s, 30s, 60s versions?

**Testing Matrix (ideal):**
- Hook (3 variants) × Proof (2 variants) × CTA (2 variants) = 12+ testable combinations

---

## 7. Fatigue & Freshness

- [ ] **Age check** — Is this creative >7 days old without refresh?
- [ ] **Frequency exposure** — Same audience seeing it repeatedly?
- [ ] **Seasonal relevance** — Does it reference outdated promos/dates?

---

## Scoring

Rate each creative 1-10 on:

| Criteria | Score |
|----------|-------|
| Strategic clarity | /10 |
| Hook effectiveness | /10 |
| Platform nativeness | /10 |
| Production quality | /10 |
| Compliance | /10 |
| Test readiness | /10 |
| **TOTAL** | /60 |

**Thresholds:**
- 50-60: Ship it ✅
- 40-49: Minor fixes needed 🟡
- 30-39: Significant rework 🟠
- <30: Do not ship ❌
