## Usage Guidelines

**Best for:**
- Facebook/Instagram ads (real photos > stock)
- Website hero images
- Google Business Profile
- Commercial pitch decks
- Review request follow-ups ("Look at the difference!")

**Tips:**
- Pair with copy like "This is what we do. Every visit."
- Before photos show the REAL problem (relatable)
- After photos show the transformation (desire)
- Real photos build trust - don't overuse the stock graphic
