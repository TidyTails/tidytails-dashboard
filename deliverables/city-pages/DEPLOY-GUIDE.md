## Deployment Steps

### 1. Upload Pages to Website (5 min)
Each HTML file goes to tidytailsstl.com as a standalone page:
- `ballwin.html` → `tidytailsstl.com/ballwin`
- `chesterfield.html` → `tidytailsstl.com/chesterfield`
- etc.

If using a builder (Wix, Squarespace, WordPress), create a new page for each and paste the HTML.

### 2. Update sitemap.xml (2 min)
Replace your current sitemap.xml with `sitemap-update.xml` (rename to `sitemap.xml`).
This includes all 13 pages (home + 12 cities).

### 3. Resubmit Sitemap in Google Search Console (1 min)
1. Go to https://search.google.com/search-console
2. Click "Sitemaps" in left sidebar
3. Enter: `https://tidytailsstl.com/sitemap.xml`
4. Click Submit

### 4. Request Indexing for Each New Page (5 min)
In Google Search Console → URL Inspection:
- Paste each new page URL
- Click "Request Indexing"
- Do this for all 8 new pages
