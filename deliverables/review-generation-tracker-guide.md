# ⭐ Review Generation Tracker — Quick Guide
*Created: March 23, 2026 10:10 PM | By: Franklin*

## What It Is
Interactive dashboard tool that tracks every Google review ask across all 8 customers. Per-customer status (not asked → asked → reviewed/declined), personalized text templates, follow-up templates, thank-you texts, notes field, and a 30-day sprint timeline.

## Dashboard
`dashboard/review-generation-tracker.html`

## Key Features
- **Per-customer cards** with status buttons (Not Asked / Asked / Reviewed / Declined)
- **Copy-paste text templates** that change based on status:
  - Not Asked → First ask template (personalized with customer name)
  - Asked → Follow-up template (gentle nudge, 5-7 days later)
  - Reviewed → Thank you template
- **Progress tracker:** Visual bar showing 0/5 → 5/5 goal
- **Stats dashboard:** Asked, Reviewed, Pending, Conversion Rate
- **Google Review link** with one-click copy
- **Notes field** per customer for tracking details
- **30-day sprint plan** with day-by-day strategy
- **Priority ranking:** 🔥 High (weekly customers) → ⭐ Medium → 📌 Low
- **All data saved to localStorage** — persists between visits
